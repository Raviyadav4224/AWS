1. What is Artificial Intelligence (AI) -

  * It is a broad field of making machines perform tasks that generally a Human would do 
    like - understanding language, Recognizing images, solving patterns, making decisions, learing from
    data etc
  
  * AI = Make machines mimic Human intelligence

2. What is Machine Learning (ML) -

  * It is a subset of AI and one of the ways through which Artificial Intelligence is achieved

  * Machine learning is a way of building AI systems that learns through PATTERNS FROM DATA instead of
    being explicitly programmed with every rule
  
  * Machine learing = Patterns + Data + Expected Results => ML Algorithm => Model => New Predictions 

3. Deep Learning (DL) -

  * Deep learning is a subset of Machine learning

  * It uses Deep Neural Networks with Multiple Layers to learn complex patterns from large amount of 
    data
  
  * Input => Neural Networks => Output

  * Traditional Machine Learning works perfectly for STRUCTURED data like predicting Buy or Not Buy
    But for complex problems like Image generation, Speech Recognition, Natural language processing,
    Recommendation system, Computer Vision, Autonomous driving requires Deep learning

4. Generative AI (GenAI) -

  * It is an AI that can GENERATE NEW CONTENT based on patterns learned from existing data

  * Instead of Prediction or Classification, GenAI can generate contents such as Text, Audio, Video,
    Images, Code

5. Foundation Models -

  * It is a Large Pre-Trained Model that can be used for many different tasks

  * Rather than training the model from scratch we can use Foundation models which are already trained
    on an existing data
    Examples Claude Sonnet, Opus 5 from Anthropic, Llama 4 by Meta, Nova by Amazon, gpt oss by OpenAI etc

6. Machine Learning Fundamentals -

  * Training Data -

    * It is a Historical data which is used to teach a Model How to recognize patterns

    * Example - Student preparing for exam is provided with Study materials and solved examples, Now
      using this the student learns the patterns from those examples
  
  * Features (INPUT) -

    * Input variables used by the Model to make a prediction is called Features
    
    * Examples - Will this person buy a car? The Model might look at - Age, salary, Existing cars,
      loans, previous purchases etc then make a prediction
  
  * Labels (EXPECTED OUTPUT) -

    * Correct outcome associated with the Training data i.e Expected Output or Target Value

    * Examples -

      Features - Area, Number of bedrooms, Location, Age
      Label - House price
      
      Features - Image information 
      Label - Cat / Dog

  * Training Set vs Validation Set vs Test Set -

    * The Overall data available for developing the data is termed as Training Set

    * Set = Training Set + Validation Set + Test Set

    * Validation Set - The data is used during development of model to evaluate and tune the Model

    * Test Set - It is unseen data which is used to evaluate the final performance of Model

    * Training = Learn
      Validation = Improve
      Test = Final Exam
    
  * Inference -

    * It is the process of using a trained model to make predictions on new data
    
    * Complete Flow -
      
      Historical Data => Split data => Training Set => Train model => Validation Set => Tune model => 
      Test Set => Evaluate final model => Deploy => New Customer => Inference => Prediction: Likely to 
      cancel

  * Overfitting vs Underfitting -

    * Overfitting - 

      Model learns the training data too closely including its Noise, thus giving poor performance
      Training accuracy     = 99%
      Validation accuracy   = 75%
      Test accuracy         = 73%
      Here the Model has learned or memorized the training data instead of learning the patterns
    
    * Underfitting -

      Model is too simple and doesn't learns the underlying patterns 

7. Types of Machine Learning -

  * Before understanding the machine learning type, ask the question - DO I HAVE A LABELLED DATA ?

  * Supervised Learning -

    * Training a Model using labelled data, where the answer is already known is termned as Supervised
      Learning

    * The model learns the relationships using inputs and known outputs

    * Example - Suppose you have 1,00,000 emails with Label as Spam or Not Spam, the Labels are already
      known so Supervised learning
    
    * Types of Supervised Learning - ( Ask the question What types of outputs we are predicting? )
        
      * Regression -

        * It predicts a Continuous NUMERICAL Value i.e Number => Regression

        * Example - 

          House price => ₹85 lakh
          Temperature => 32.5°C
          Revenue => ₹12.7 lakh
          Delivery time => 42.5 minutes
          Stock price => $182.50
          A company wants to predict the monthly sales revenue based on historical sales data, 
          marketing spending, and seasonality => answer is a Number so Regression

      * Classification -

        * It predicts a CATEGORY or CLASS i.e Output is a Category => Classification

        * Examples - 

          Spam / Not Spam
          Fraud / Not Fraud
          Cat / Dog
          Approved / Rejected
          High / Medium / Low
        
        * Binary Classification - Two possible classes such as Fraud / Not Fraud, Spam / Not Spam etc

        * Multi-class Classification - More than two classes possible, such as Image - Dog, Cat, Horse, 
          Bird etc

  * Unsupervised Learning -

    * In Unsupervised learning, model finds patterns or structures WITHOUT using predefined Labels
      i.e Model discovers the patterns itself
    
    * Example -

      An e-commerce company has -

        Customer A => ₹5,000/month, buys electronics
        Customer B => ₹6,000/month, buys electronics
        Customer C => ₹800/month, buys groceries
        Customer D => ₹900/month, buys groceries
        Customer E => ₹20,000/month, buys luxury products

        You don't provide groups, The algorithm might discover -
        Group 1 => Electronics shoppers
        Group 2 => Grocery shoppers
        Group 3 => Premium shoppers
        That's unsupervised learning

    * Clustering -

      * Clustering groups similar data points together without predefined labels
        The model is not provided with groups beforehand, rather it discovers them using Algorithms
      
      * Famous Algorithm - K-Means Algorithm
        i.e Customer Data => K-Means Algorithm => Group A(Budget customers), Group B(Regular customers),
        Group C(Premium customers)
        The groups were not given beforehand, The algorithm discovered them

    * Association Rules -

      * Discovering relationships between items that are frequently occuring together is termed as 
        Association rules
      
      * Example - If a person buys a Laptop, he might also buy a Laptop bag or Mouse, this is called 
        Association
      
      * Association algorithm => Apriori

    * Anomaly Detection -

      * The system determines unusual or abnormal data points that differ significantly from the normal
        behavior
      
      * Example - Credit-card fraud, Network attacks, Manufacturing defects, Unusual user behavior, 
        Equipment failure
      
      * Famous Algorithm => Isolation Forest
